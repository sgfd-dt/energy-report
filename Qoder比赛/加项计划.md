## 四、异常标签错位（2026-11-18 16:40 定位 + 已本地验证修法）

**现象**：窗口一窄，原始数据那张表就错位——行底横线只画到一半，标签浮在表格外面。

**根因**：第 1 段 prompt 里我写的是「这一行末尾加一个小标签」，Qoder 照字面理解成**新加一个 `<td>`**（app.js:347-354 `tagCell`）。表头只有 4 列，异常行却有 5 个单元格，于是表格被算成 5 列、宽度超出卡片，容器出现横向溢出。

**验证方法**（以后复查布局都这么干，比让用户拍照可靠）：把线上 index.html / app.js / styles.css 拉到本地，改 `SAMPLE_CSV` 一行造假异常，用无头 Chrome 在多个宽度截图：
`"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --hide-scrollbars --allow-file-access-from-files --virtual-time-budget=5000 --window-size=700,1900 --screenshot=out.png file:///D:/DSH/shots/site/index.html`
实测：960 宽时勉强正常，**700 宽时行线只到 470px、标签落在 490–620px 外面**，确认是第 5 列导致。

**修法（本地已试过：700 与 960 都正常，行线铺满、标签跟在「900」后面）**：

```
异常标签现在是新加了一个单元格（第 5 个 td），而表头只有 4 列，窗口一变窄整张表就错位。
只改这一处，其他都不动：

1) 删掉为了放标签而新加的那个 td（含 tagCell、tr.appendChild(tagCell)），
   改成把标签 span 直接追加到「电量」那一列的 td 里（数字后面）。
2) 标签加 margin-left: 8px，其余样式不变。
3) 删掉 .anomaly-cell 相关的所有 CSS 规则（含手机上那两条 grid-column / grid-row）。
4) 手机上（≤640px）允许标签在电量数字下面换行（white-space: normal），不要撑出横向滚动。

约束：不动其他任何样式与逻辑；三份数据对账仍是 2056.30 / 474.10 / 263.60；异常版仍是 2730.70、1 行、2.6 倍。
```

**教训**：给 Qoder 写「加一个标签」时，必须说明「加在哪个已有单元格里」，否则它会新开一列。

**结果（2026-11-18 16:55 已验证）**：线上 app.js:346 改成 `td.appendChild(tag)`，`.anomaly-cell` 规则全删（grep 0 命中）。我用无头 Chrome 在 760 / 960 / 375 三个宽度截图确认：行线铺满卡片、标签跟在「900」后面、375 窄屏是设备名+日期两行 + 电量右对齐、无横向滚动。

**测窄屏的坑（记下来）**：`chrome --headless --window-size=375` 实际视口最小是 500px，截出来的图是**裁切**不是缩窄，会让人误判成「手机布局溢出」。要真测 375，用一层 `iframe` 限宽（`<iframe style="width:375px">` 包住页面）再截图，或者用 CDP 的 Emulation.setDeviceMetricsOverride。判断溢出更可靠的办法是在页面里插一段脚本读 `document.documentElement.scrollWidth` 和 `clientWidth`（用 `--dump-dom` 把结果打出来）。
