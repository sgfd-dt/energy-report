# 炒股复盘器 · 使用说明

> 这不是「选股软件」。它不预测涨跌、不推荐股票、不连券商、不会帮你下单。
> 它只做一件事：**把你自己做过的交易记下来，算出你到底是怎么亏钱的。**

---

## 一、30 秒开始

1. 双击本文件夹里的 **`运行复盘.bat`**
2. 出现菜单后，输入 **`6`** 回车（写入 8 笔样例数据）
3. 再输入 **`3`** 回车（出复盘报告）

你看到的那份报告，就是三个月后你会拿来自救的东西。

> 样例数据是我编的假交易，看完之后把 `trades.csv` 删掉，或者直接开始记你自己的。

---

## 二、它到底算些什么

| 指标 | 含义 | 怎么算「还行」 |
|---|---|---|
| 胜率 | 赚钱的交易占几成 | 短线 40% 左右就够，关键看下面那个 |
| 盈亏比 | 总赚的钱 ÷ 总亏的钱 | **低于 1.5 基本活不下去**，2 以上算优秀 |
| 期望值/笔 | 平均每笔赚（或亏）多少 | **必须是正数**，否则交易越多亏越多 |
| 最大回撤 | 账户从最高点往下缩得最狠的那一次 | 决定你会不会心态崩、乱操作 |

记住一个关系：**胜率只有 35%，但盈亏比 3.0，照样能赚钱；胜率 80%，但盈亏比 0.3，照样亏光。**
散户最常见的死法不是「选错股」，是「赚 3% 就跑、亏 20% 死扛」。

---

## 三、报告里最有用的两块

**① 按买入理由分组**

它会告诉你：钱是从哪条路进来的，又从哪条路漏掉的。等你攒到 20 笔左右，多半会看到一个残酷的事实——
「消息/群里听说」「情绪冲动」「朋友推荐」这三类的累计盈亏是负的，而你自己研究过的那一类是正的。

**② 按执行分组**

守纪律（按计划止损/止盈）的交易 vs 没守的，累计盈亏一比就出来了。
这一栏通常比「选股能力」更值钱。

---

## 四、每周固定动作（15 分钟）

1. **卖出一笔就记一笔**（菜单 `1`）。没卖的先别记。
2. **周末出一次报告**（菜单 `3`），报告会自动存成 `复盘报告.txt`。
3. 只看「自动诊断」那三条，**下周只改其中一条**。

改一条、看一周、再改一条。三个月下来你会明显不一样。

## 五、数据放在哪

- `trades.csv` —— 就是你的账本，**可以用 Excel 直接打开**。
- 别改列名，别删列。删掉这个文件 = 清空重来。
- 新记录会追加，旧记录不会丢。

## 六、六条不写在代码里的铁律

1. **只用闲钱**——亏光也不影响吃饭交学费的那种钱。
2. **单笔不超过总资金的 10%**（学习期）。仓位小，错了才有下一次。
3. **买入前先写止损价**，写进「备注」栏。写不出来就别买。
4. **不加杠杆**：不碰融资融券、不碰期权、不借钱炒股。
5. **连着亏 3 笔就停手一周**，回去看报告，不是回去加仓。
6. **不给任何人操作你的账户**，不听荐股群喊单，不装来路不明的「AI 选股」App。

## 九、第二个程序：规则提醒器 `signal.py`

它是给你问「什么时候该买、什么时候该卖」的那一半答案。**注意是哪一半。**

双击 `运行提醒.bat`（或 `python signal.py`）→ 选 `1`，它会：

1. 拉你自选股的日 K 线（东方财富公开接口，要联网）
2. 用四条写死的规则（MA20 上穿买 / 下穿卖 / MA60 跌破走 / 偏离 8% 警告）算一遍
3. 每条提示都写清**是哪个数字触发了哪条规则**
4. 顺手把**这条规则在这只股票过去两年的胜率、收益**贴给你，并和「买入后什么都不做」对比

第 4 步是关键。我拿 4 只股票跑出来的结果是：**3 条规则跑输了「买入不动」**。
这不是程序坏了，这是技术指标的真实水平——规则细节、怎么读体检结果、怎么自己改规则，全在 **`规则说明.md`** 里。

一句话记住：**它给的不是「该买了」，是「你的规则今天说了什么，以及它过去准不准」。**

## 十、第三个程序：K 线图 `kline.py`

双击 **`看K线.bat`** → 输入编号（1=茅台、2=长电…）→ **浏览器会自动弹出一张 K 线图**。

看到的东西：

| 元素 | 是什么 |
|---|---|
| 红/绿柱子 | 每天的四个价格。**红=涨（收>开），绿=跌**。细线是当天最高/最低 |
| 橙线 MA5 | 最近 5 天平均价，很敏感，一天一拐 |
| 蓝线 MA20 | 最近 20 天平均价，一个月的成本线 |
| 紫线 MA60 | 最近 60 天平均价，一个季度的大方向 |
| 下面一排柱子 | 成交量（当天交易了多少手），红绿跟着涨跌 |
| ▲ 红三角 | 规则提醒器说的**买点**（收盘上穿 MA20，且 MA20 在 MA60 上方） |
| ▼ 绿三角 | 规则说的**卖点**（收盘下穿 MA20） |

**能做的操作：**

- 鼠标在图上移动 → 显示那一天的开/收/高/低、涨跌幅、成交量、三条均线的值
- 底部拖动滑块 / 滚轮 → 缩放和左右移动（默认只画最近 250 根，够看一年）
- 关掉网页不影响，重新双击 `看K线.bat` 会重新拉最新数据再画

**为什么图上那些三角不能当信号？** 因为它们就是 `signal.py` 的四条规则画出来的，而
`规则说明.md` 里已经算过了：这套规则在茅台过去两年跑输「买入不动」10 个百分点。
三角形只是让你**看见规则长什么样、错在哪里**，不是让你照着做。

**想一次看很多只？** 改 `自选股.csv`（记事本打开，一行一只：`代码,名称`），
然后菜单里编号就跟着变了。

**生成的图在哪？** 同目录的 `K线图.html`，双击可直接打开——图是自带在文件里的，
断网也能看，转发给别人也能看。

**看图的正确姿势（第一课）：** 找几个「▲ 之后马上又出现 ▼」的地方，
数一数这种来回打脸一年会发生几次——这就是均线策略的真实成本。



## 十一、第四个程序：桌面 App「股市助手」

**一句话：** 双击桌面上的 `股市助手` 图标，就是一个窗口程序——左边自选股、中间 K 线、右边规则体检。

### 怎么打开
- 双击桌面 `股市助手` 图标（快捷方式）
- 或者进 `D:\ai的文件\python练习\炒股复盘\股市助手\`（桌面 `炒股复盘\股市助手\` 里也有一份），
  双击 `股市助手.exe`，或双击 `启动股市助手.bat`
- **exe 不能单独拖出来用**：同目录的 `_internal` 文件夹和 `自选股.csv` 必须跟它待在一起

### 界面怎么用（3 步）
1. 左上角输入代码（例如 `000858`）→ 点「看这只」→ 整张图换股票；点「刷新数据」拉最新
2. 下方 `3个月 / 半年 / 1年 / 全部` 切时间范围；鼠标滚轮缩放，`←` `→` 左右平移
3. 鼠标停在 K 线上 → 弹出那天开/收/高/低、涨跌幅、成交量、三条均线；
   如果那天触发了规则，还会写清「为什么触发」

### 右边「规则体检」怎么读
- **趋势 / 离 MA20**：现在是不是多头、价格离 20 日均线多远（茅台 2026-10-30 是「多头排列、离 MA20 +6.46%」）
- **规则提示**：今天有没有触发买卖规则。**大部分日子显示「今天没有触发任何规则」才是正常的**
- **这条规则过去有多准**：统计区间 + 几笔交易 + 胜率 + 盈亏比 + 最大回撤 + 规则收益 vs 买入不动

**最重要的一句：** 图上的 ▲▼ 和右边的「几笔交易」是一一对应的——同一条规则、同一段时间。
茅台最近两年这条规则：9 笔、胜率 22.2%、规则 -14.3%，而买入不动 +6.5%（输 20.9 个百分点）。
这不是程序坏了，这是均线规则的真实成绩。**看它的意义是知道它不行，不是照着它下单。**

### 常见问题
- 窗口闪一下没了 → 双击 `启动股市助手.bat`，黑窗里会留报错；多半是 `_internal` 文件夹丢了
- 显示「拉取失败」→ 网络或东财接口的问题，点「刷新数据」重试
- 第一次打开慢一两秒 → 正常，程序要把自己解压到内存里
- 想加自选股 → 窗口左下输入代码点「加入」；也可以直接用记事本改 `自选股.csv`

| 你输 | 会得到 |
|---|---|
| `招商银行` | 600036 招商银行 |
| `zsyh` | 600036 招商银行（拼音也行） |
| `600036` | 直接命中 |
| `银行` | 名字带「银行」的 A 股，最多列 10 只 |

### 搜索没反应怎么办（按顺序查这三步）

1. **看窗口左上角有没有「搜索股票」这一栏**，以及它下面那行小字（`中文 / 拼音 / 代码`）。
   没有 → 你开的是加搜索之前的旧窗口：把窗口关掉，重新双击桌面上的「股市助手」。
2. **输完按回车，或点右边的「搜索」按钮**。搜索框正下方会立刻出现一行状态字：
   `正在搜「xxx」……` → 变成 `搜到 N 只，选一个`，并弹出小窗口，**双击一行**就打开。
   如果变成红色 `没搜到「xxx」，换个词试试` → 这个词没匹配到 A 股，换成 6 位代码再试。
3. **还是不行就看日志**：打开 `股市助手` 文件夹里的 `调试日志.txt`，最后几行写着具体原因
   （搜索用哪个源、失败信息都记在里面），把它发我就能定位。

小提示：
- 现在**顶部那个「代码」框**也能直接输中文/拼音，程序会自动把它当搜索词去查。
- 用中文输入法时，等候选框的字**上屏**了再按回车；还在拼音状态时回车是被输入法吃掉的。

### 怎么自己加股票、怎么删（2026-10-30 补）

**加一只股票，三种方法任选：**

| 方法 | 怎么做 |

## 十二、第五个功能：新闻 · 公告 · 研报（右侧第二个标签页）

点右边面板顶部的「新闻·公告」标签就切过去了。里面有两样东西：

**1. 最近公告**（东财公告接口，一次拉 100 条，按日期从新到旧）

每行是：`日期  种类  标题`

- 种类只有六种：业绩 / 分红 / 增减持 / 并购重组 / 融资 / 风险 / 其他
- 种类是按标题里的事件词分的（比如标题里有「半年度报告」就是业绩类）。
  这个比「偏多/偏空」可靠，因为它数的是"这是什么事"，不是"好不好"
- **双击任意一行 → 浏览器打开原文**

**2. 机构研报**（近一年最多 8 篇）

前面是机构名，后面是标题，带它的评级（买入/增持…）。评级是机构的观点，不是事实。

### 下面的蓝框：公告发出来之后，历史上涨了多少

```
            1日     3日     5日
比平时   -0.1%  -0.6%  -0.6%
上涨率     42%    33%    42%
```

- **比平时** = 公告后 N 日的平均涨跌，减去"随便哪一天买入持有 N 日"的平均涨跌。
  正数＝公告后确实比平时偏涨；负数＝偏跌。
- **上涨率** = 公告后 N 日收盘价比公告那天高的次数占比。
- **按公告种类（5日后）** = 同样的算法，分组看哪类公告之后更容易涨。

### 三条必须记住的

1. 这里接的是**公司公告 + 机构研报**，不是门户网站的"新闻"。媒体新闻的接口大多
   要登录或反爬，拉不稳；公告是公司自己发的原文，能稳定拿到。
2. 「像利好 20 条」这种标签只是**数标题里的词**，不等于真会涨。
3. 蓝框里是**历史统计**：样本少、公告还可能扎堆在某个月（比如中报季），
   差别再大也别当因果，更别当买卖指令。

### 拉不到怎么办

- 蓝框显示"没有可用的公告日期"：多半是这只没有公告（ETF、指数没有公司公告）。
- 标题上方显示"有接口没通"：网络问题，点「刷新数据」重试；仍不行就看 `调试日志.txt`。


## 十三、第六个功能：今天怎么办（买入 / 卖出 / 先不买）

点右边面板最左边的「今天怎么办」标签。它给出**一句话结论 + 一个分数 + 每条理由**。

### 先说清楚：这不是我的建议，也不是预测

这是一套**写死在代码里的机械规则**：6 条，每条加减固定分数，最后加起来看正负。
好处是「可复核」——你能看到它是怎么算出来的；坏处是「不等于正确」。
所以下面还会把这个规则在**这只股票上过去的表现**一起摆出来。

### 六条规则（每条都能在图上验证）

| # | 规则 | 加分 |
|---|---|---|
| 1 | MA20 在 MA60 上方（中期趋势向上） | +2；下方 −2 |
| 2 | 收盘价在 MA20 上方 | +1；下方 −1 |
| 3 | 离 MA20 超过 8%（追高了） | −1 |
| 4 | MA20 自己在往上走（比 5 天前高 0.3% 以上） | +1；下拐 −1 |
| 5 | 收盘是近 20 个交易日最高价 | +1；最低价 −1 |
| 6 | 近 5 天成交量是 20 天均量的 1.3 倍，且价格在线上 | +1；放量下跌 −1 |

### 结论怎么读

- **未持有**：分数 ≥3「规则说可以买（分两次进）」；≥1「先别买，等它站稳 MA20」；
  ≥−1「先不买」；更低「别买（趋势向下）」
- **勾上「我已经持有这只股票」**：≥3「继续持有」；≥1「持有，但别加仓」；
  ≥−1「减掉一部分」；更低「考虑卖出」

### 一定要看的两行小字

1. **⚠ 过去跑输 / 跑赢 买入不动 X 个点** —— 这条规则在这只股票的历史成绩。
   比如贵州茅台现在规则说「可以买」，但这套规则过去比「买了就不动」少赚 20.9 个点。
   **看到「跑输」就别照单全收。**
2. **规则在哪改口** —— 明确的价位：收盘跌破 MA20 多少，规则就翻成卖点；
   跌破 MA60 多少，规则直接叫你离场。这是唯一「可执行」的部分。

> 记住：规则给的是「按这套算法现在该干什么」，不是「明天会涨还是跌」。


## 十四、第七个功能：实时报价（顶栏那个「实时」勾）

### 它是什么

顶栏右边多了个「实时」勾选框（默认勾上）。勾着的时候：

- **盘中**（周一到周五 9:15–11:35、12:55–15:05）：每 **5 秒**去拿一次最新价，
  顶栏那个大数字会自己跳，右边的字是蓝色「实时 10:31:05」。
- **收盘后 / 周末**：不再发请求，右边是灰色「已收盘 16:14:55」——
  那个时间是交易所最后一次更新的时间，价格就是当天收盘价。

### 图上的最后一根也会跟着动

如果今天已经有日线（说明今天开盘了），盘中的实时价会把**最后一根 K 线**的
收盘、最高、最低一起改掉，所以那根「今天的柱子」是活的；一收盘就定住了。

### 三个必须知道的限制

1. **不是逐笔（Level-2）**：这是免费公开接口，延迟大约 3–15 秒，
   看不到每笔成交、看不到挂单队列。真要做高频，得买行情商的数据。
2. **只有交易时段会跳**：非交易日、午休、盘后都不动，这是正常的，不是程序坏了。
3. **接口会抽风**：东财不通会自动换腾讯；两个都不通，"实时"旁边会显示
   「实时拿不到价」并在 `调试日志.txt` 里留一行。点一次「刷新数据」能重试。

### 关了它会怎样

不勾「实时」= 完全手动：只有点「看这只 / 刷新数据」时才去拿数据，
平时一个网络请求都不发（省流量、也避免被接口限流）。


## 十五、第八个功能：公司简介（右侧第四个标签页）

点右边最上面第四个「公司简介」，会显示这家公司的公开资料，分三块：

1. **一、这家公司是干什么的**：官方简介原文（来自年报/招股书口径）。
2. **二、基本信息**：全称、曾用名、上市时间、所属行业、证监会分类、员工人数、
   注册资本（亿元）、董事长、法人代表、公司地址、联系电话、公司网站。
3. **三、主营与经营范围**：主营什么、营业执照上允许做什么。

最底下一行会写数据来源（东财数据中心，取不到时退到 F10 页面）。

### 三条必须记住的

1. **这是「搬运」不是「分析」**。我只是把交易所/公司公开披露的资料摆到这里，
   不评价它是好公司还是坏公司。
2. **简介是公司自己写的**，会挑好听的说；员工人数、注册资本这类数字一年才变一次。
3. **「贵不贵」「值不值得买」不在这页**。那要看财报三张表（营收、净利、现金流）
   和估值（市盈率、市净率），这页只回答「它靠什么赚钱」。

### 换股票会跟着换

看别的股票时，这页会自动重新取那家公司的资料（接口同时支持沪市 6 开头、
深市 0/3 开头、北交所 4/8/9 开头）。取不到会在这页顶部提示，不影响 K 线。


## 十六、第九个功能：周期切换（分钟 K 线）

图上有一排「周期」按钮：**日线 / 60分 / 30分 / 15分 / 5分 / 1分**。

- 点「1分」：一根蜡烛 = 1 分钟，看的是最近几天里每一分钟的价格。
- 点「5分 / 15分 / 30分 / 60分」：一根蜡烛 = 5/15/30/60 分钟，能往回看更久。
- 点「日线」：回到原来的日 K 线。

### 每个周期最早能看到什么时候（接口上限 1023 根）

| 周期 | 最多回溯 |
|---|---|
| 1 分 | 约 4~5 个交易日 |
| 5 分 | 约 1 个月 |
| 15 分 | 约 3 个月 |
| 30 分 | 约 6 个月 |
| 60 分 | 约 1 年 |
| 日线 | 好几年（要多少有多少） |

### 换成分钟线之后，哪些东西变了

- **变了**：图上只画价格、均线和成交量，**不画买卖点三角形**（买卖点那套规则是按日线定义的，
  硬画到分钟线上会前后不一致）。
- **没变**：右边三页（今天怎么办 / 规则体检 / 新闻公告）永远按**日线**算，
  所以换周期不会让结论跳来跳去。
- 底部「3 个月 / 半年 / 1 年 / 全部」按钮在分钟线模式下会变灰（它们只对日线有意义）。

### 三条必记

1. 分钟线只是同一段价格的**放大镜**，不是新信息；越细，噪声越多。
2. 1 分钟线看不到更早的历史——这是免费接口的上限，不是程序的问题。
3. 越短的周期交易越频繁，手续费会吃掉更多收益（A 股来回一次千分之几）。
