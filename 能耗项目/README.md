# 能耗记录器

把电表导出的 CSV 变成一句能拿去汇报的结论：**哪台设备最费电、该先查谁。**

- 一行命令出报告，报告格式固定、可以直接贴进周报
- 坏数据（空电量、写错的数、少一列）自动跳过并计数，不崩
- 电量换算成**电费和碳排**：`2056.30 度 ≈ 1233.78 元 ≈ 1.19 吨 CO₂`
- 接了一个大模型，可以随口问「哪台最该先查」，它读报告回答

> 作者：大一 · 能源与动力工程。做这个的起点很朴素：工厂每月都在为电费头疼，但抄表数据躺在 Excel 里没人算得动。

## 对账（三份数据、三套已知答案）

同一份程序跑不同数据，结果必须和手算一致，这就是验收标准：

| 数据 | 合计电量 | 跳过行数 |
|---|---|---|
| `能耗示例.csv` | **2056.30 度** | 0 |
| `能耗示例_坏数据.csv` | **474.10 度** | 1 |
| `能耗示例_更坏数据.csv` | **263.60 度** | 3 |
| `能耗示例_异常.csv` | 2730.70 度（另标 1 行异常） | 0 |

四台设备拆分（好数据）：锅炉C 1028.00 / 空压机A 638.60 / 冷却塔B 222.10 / 风机D 167.60。

**为什么要对账**：手写版和 pandas 版都算同一份数，两个结果一致才说明逻辑没错——比"跑通了"强得多。
