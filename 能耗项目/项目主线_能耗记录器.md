## 一、主线项目是什么

一个能在终端里跑的小工具，读工厂/宿舍楼的用电记录表，回答这类问题：

- 哪台设备最耗电？
- 这个月比上个月多了多少度？
- 有没有设备「运行小时很少但耗电很高」（异常）？

数据就用同目录的 `能耗示例.csv`（自己编的假数据，随便改）。

为什么是这个项目：它和你专业同频，面试时能讲出场景；而且每一步都能跑出来看见结果，不会学了三周还在背语法。

---

## 二、七个里程碑（一个里程碑 = 一个能跑的新版本）

| 里程碑 | 做成什么 | 这一步才学的语法（≤5 个） |
|---|---|---|
| M1 读进来 | 读 csv，打印前 5 行，说出一共有几条 | `with open()`、`csv.reader`、`for`、列表切片 `[:5]`、`len()` |
| M2 算出来 | 按设备汇总耗电量，从大到小排 | 字典累加 `d[k] = d.get(k,0)+v`、`float()`、`sorted(..., key=..., reverse=True)` |
| M3 查得到 | 菜单：1 看全部 2 按设备查 3 看总额 0 退出 | `def` 函数、`while True`、`if/elif`、`return` |
| M4 存下来 | 把结果写成 `报告.txt`，格式整齐 | 写文件 `"w"`、`f"{x:.2f}"`、`\n`、`"─"*30` |
| M5 不崩 | 坏行自动跳过，并告诉你有几行被跳过 | `try/except ValueError`、`continue`、计数器 |
| M6 换引擎 | 用 pandas 重写 M2，对比两版代码行数 | `pd.read_csv`、`groupby`、`sum`、`sort_values` |
| M7 会说人话 | 接一个大模型 API，直接问「哪台最耗电」，让它生成一句话结论 | `requests`、API Key、messages/role、JSON 解析 |

之后才进阶段二（RAG / Function Calling / Agent 循环），用的还是这个项目的数据。

## 四、M1 的代码（先照抄跑通，再关掉教程自己敲一遍）

```python
import csv

FILE = "能耗示例.csv"

with open(FILE, encoding="utf-8") as f:
    rows = list(csv.reader(f))

print("表头:", rows[0])
print("行数:", len(rows) - 1)

for r in rows[1:6]:
    print(r)
```
