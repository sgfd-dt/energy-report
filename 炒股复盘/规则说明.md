# 规则提醒器 · 它凭什么说话，以及它凭什么不值得你全信

> 这个程序的每一句提示都是**写死的规则 + 具体数字**，不是我的判断，也不是任何人的判断。
> 你要学会的不是"照着提示买"，是**看懂一条规则值不值得信**。

---

## 一、四条规则原文（就在 `signal.py` 里，你可以改）

| 编号 | 规则 | 想解决什么 |
|---|---|---|
| R1 | 收盘 > MA20 > MA60 才算多头排列 | 趋势过滤：只在方向朝上时考虑买 |
| R2 | 昨天收盘在 MA20 下方、今天站上 MA20 → **入场信号** | 用一条均线定义"跌势转涨势" |
| R3 | 昨天在 MA20 上方、今天跌破 → **离场信号** | 同样的线，反过来用 |
| R4 | 收盘比 MA20 高出 8% 以上 → **追高警告**；跌破 MA60 → **离场信号** | 防止你追在天花板上 |

MA20 = 最近 20 个交易日收盘价的平均线，代表"最近一个月大家的平均成本"。
MA60 同理，代表"最近一个季度"。

**为什么用这两条线？** 因为它们是最古老、最透明、最不容易骗人的规则。全世界都这么用，所以它**不会给你超额收益**——这一点后面会算给你看。

---

## 二、每条提示都带「原因」，原因里必须出现数字

示例：

```
【入场信号】上穿 MA20
  原因：昨天收盘 1352.10 在 MA20（1340.50）下方，今天收盘 1361.00 站上去了 → 触发规则 R2。
        趋势过滤 R1：多头排列，符合
```

它绝不会说"这只票要涨了"——因为**没有任何程序知道**。它只说"哪个数字触发了哪条规则"。

这也是一切靠谱系统的基本素养：**结论可以错，推导必须看得见**。

## 三、最狠的那一行：规则体检

每只股票下面都有一行：

```
规则体检（2025-01-07 ~ 2026-10-30，23 笔）：胜率 34.8%，盈亏比 1.34，
规则收益 +4.8%，同期买入不动 +11.1%，最大回撤 5.6%
⚠ 同一段时间里，这条规则跑输「买入后什么都不做」6.4 个百分点。
```

这是我在最初跑这批股票时得到的结果，你跑也会类似：**四条教科书规则，在多只股票上跑输"买入后什么都不做"。**

这不是程序写错了，这就是真相：

- 技术指标是公开的，所有人都能看到，所以它**不构成信息优势**；
- 频繁买卖会不断付手续费（还记得 `journal.py` 里算的那 0.15% 吗？23 笔就是 3.5%）；
- 胜率 30% 出头很正常，重仓的人根本扛不住。

**那为什么还留着这个功能？** 三个理由：

1. 它把"我觉得要涨"翻译成了一句**可以被检验**的话；
2. 它逼你在下单前先看完整历史，而不是只看最近三根阳线；
3. **这正是 Agent 工程师的核心训练**——写一条规则、让机器执行、再用数据检验它。你的目标岗位每天都在干这件事。

## 四、你要练的三个动作

**① 改参数，看结局怎么变**
把 `signal.py` 里的 20 改成 5 或 60（MA20 → MA5 / MA60），重跑 `python signal.py backtest 600900`。
你会发现：换个数字，收益能差一倍——**这就是"过拟合"的入口**。参数调得越漂亮，将来的脸打得越响。

**② 找一条跑赢"买入不动"的规则**
如果找到了，先别高兴，把股票换成另外五只再跑一遍。只在原来那只上有效 = 巧合。

**③ 给它加一条规则**
比如"连续 3 天放量上涨才算突破"。加在 `today_signals()` 里，然后跑体检看它到底是加分还是减分。
**这是你第一个真正的策略研究动作**，比任何教程都实在。

---

## 五、三条底线（写在这里，比写在代码里重要）

1. 这个程序**不联网下单、不接你的账户**，它只是把你自选股的公开 K 线算一遍。
2. 它给的从来不是"什么时候买"，而是"你的规则今天说了什么"。
3. 任何声称能预测点位、保证胜率的工具，都是在骗你——包括长得跟这个程序很像的。
